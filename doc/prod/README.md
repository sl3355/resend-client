# Product documentation

Draft baseline · 2026-10-14 · Working name: Resend Client

Start with the [product requirements](./product-requirements.md), then the [experience and acceptance criteria](./experience-and-acceptance.md).

The proposed first release is a personal desktop email client for an existing Resend account. It provides familiar email workflows on macOS Apple Silicon, macOS Intel, Windows ARM64, and Windows x86-64. It uses the established sending and receiving APIs, with local drafts and organization. Resend's private-beta Inboxes API is an optional future path, not a release dependency.

These are proposed requirements, not implemented capabilities. Domain registration and working DNS are user-provided facts; account permissions, limits, retention, and beta access have not been tested against the user's account. No credentials are required to review these documents.

Technical evaluation, architecture, provider evidence, and delivery gates are in [technical documentation](../tech/README.md).
